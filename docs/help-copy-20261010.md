### Writing Contract

Audience: people comparing AI models, not implementers. The guide is an explanation with short how-to steps; popovers answer the immediate question. Lead with the consequence or action. Use concrete examples before arithmetic. Define benchmark versions and run settings before relying on those terms. Keep complete calculation rules in the guide, not in every hover message. Do not alter scoring or invent capabilities to make the explanation easier.

### Risk Assessment

No public API changes, database migrations or scoring changes. Existing drafts, weights and concurrent source changes must be preserved. Verify copy against current behavior, especially name-only inspection, no unsearched folding, shared fallback selection, strict matching and estimated coverage.
